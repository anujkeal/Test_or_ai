# NEXUS UI design rules

For every UI creation, redesign, critique, or polish task, read and follow:
- `human-ui-design/SKILL.md`
- `human-ui-design/references/anti-ai-ui-rubric.md`
- `human-ui-design/references/app-mobile-ui.md`

NEXUS is a mobile-first, on-device AI assistant with optional user-configured cloud API mode. Design for the real chat, workspace, model, memory, phone-action, and code-execution workflows. Preserve functionality and privacy disclosures.

Use a restrained technical-sharp direction: neutral reading surfaces, purposeful status color, precise typography, stable controls, useful dividers, and task-specific structure. Avoid generic gradient/hero/card compositions, emoji in UI chrome, decorative icon soup, and nested card layouts. Prefer native Compose controls and the existing project assets.

Before finishing UI work, check loading, ready, error, empty, keyboard-open, safe-area, permission-denied, and long-content states where relevant. Do not build an APK unless the user explicitly asks.
